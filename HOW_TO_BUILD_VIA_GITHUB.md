# Как получить установочные файлы — без установки чего-либо на свой компьютер

Ничего компилировать не нужно. GitHub соберёт всё сам на своих серверах,
бесплатно. Вам нужно один раз загрузить папку с кодом — дальше сборка
происходит автоматически при каждом изменении.

## Шаг 1 — создать бесплатный аккаунт GitHub

Если его ещё нет: https://github.com/signup

## Шаг 2 — установить GitHub Desktop (просто программа с окнами, не консоль)

Скачать: https://desktop.github.com/ — обычный `.exe`-инсталлятор, ставится
как любая программа.

## Шаг 3 — создать репозиторий и загрузить код

1. Откройте GitHub Desktop → войдите под своим GitHub-аккаунтом.
2. `File → New Repository`.
3. Name: `ResellerSystem` (или любое имя). Local Path: выберите папку рядом
   с той, куда вы распаковали присланный архив.
4. Нажмите `Create Repository`.
5. Скопируйте **все файлы и папки** из распакованного архива `ResellerSystem.zip`
   в только что созданную папку репозитория (просто перетащить в Проводнике
   Windows).
6. Вернитесь в GitHub Desktop — он сам покажет список всех новых файлов
   слева.
7. Внизу слева впишите любое сообщение (например `initial commit`) и
   нажмите `Commit to main`.
8. Нажмите `Publish repository` вверху. **Снимите галочку "Keep this code
   private"**, если хотите использовать бесплатные раннеры GitHub Actions
   без ограничений (для приватных репозиториев тоже бесплатно, но есть
   лимит минут в месяц — публичный репозиторий не ограничен).
9. Нажмите `Publish Repository`.

Готово — код на GitHub.

## Шаг 4 — сборка запустится автоматически

На GitHub уже лежит файл `.github/workflows/build-release.yml` — GitHub
увидит его и запустит сборку сам, как только вы опубликуете репозиторий.

1. Откройте ваш репозиторий на github.com в браузере.
2. Вкладка **Actions** вверху страницы.
3. Увидите запущенный workflow "Build Release" — жёлтый кружок = идёт
   сборка, обычно 10-15 минут.
4. Когда станет зелёная галочка — сборка готова.

## Шаг 5 — скачать установочные файлы

1. Кликните на завершённый запуск (зелёная галочка).
2. Внизу страницы — раздел **Artifacts**:
   - `windows-installers` — здесь `ResellerSystem-Server-Setup.exe`,
     `ResellerSystem-Client-Setup.exe`, файл обновления и манифест.
   - `macos-installer` — здесь `ResellerSystem-macOS.dmg`.
3. Кликните — скачается `.zip` с готовыми файлами.

## Если сборка упадёт с ошибкой (зелёного не будет)

Откройте упавший запуск → кликните на шаг с красным крестиком → увидите
текст ошибки. **Скопируйте этот текст и пришлите мне** — я вижу код (он
теперь публично на GitHub, если вы не сделали репозиторий приватным) и
смогу поправить прямо в файлах, вы просто загрузите обновлённую версию
через GitHub Desktop (`Commit` → `Push`) — сборка перезапустится сама.

## Дальше — каждое следующее обновление

Как только я дошлю вам исправленные файлы (или сам буду говорить, что
поправил), вам нужно будет всего лишь: скопировать изменённые файлы поверх
старых в папке репозитория → GitHub Desktop сам покажет, что изменилось →
`Commit` → `Push origin` — и сборка снова запустится автоматически.
